# Example feature specs (Todo sample)

Unchanged copies of the five feature specs from the OC CS Speckit **Todo** sample app (`todospeckit-dev.zip`). `features/framework.md` and the writing guides link here as the canonical examples.

- They are **not** Vehicle Reservation requirements. They live outside `features/`, so the Agility import and the spec PDFs skip them.
- To start a spec, copy one into `features/feature-N-short-name.md`. Keep its `**As a**` / `**As the**` story lines and `*` Gherkin bullets — the Agility import needs both.
- Feature 1's links to Todo ADRs 0001 and 0002 don't resolve here; those ADRs aren't part of the starter kit.
